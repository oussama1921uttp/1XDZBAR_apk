تطبيق أندرويد لموقع 1XDZBAR (WebView + إشعارات)
==================================================

ماذا يفعل التطبيق؟
- يعرض موقعك https://1xdzbar.vercel.app/ داخل تطبيق.
- يعرض إشعارات على الهاتف عند: وصول رسالة جديدة، طلب صداقة، تحويل مال، أو شراء أحدهم عملتك في P2P.
- الضغط على الإشعار يفتح الصفحة المناسبة (المحادثة، الأصدقاء، السجل).

الخطوة 0 (مهمة): حدّث الموقع أولاً
الموقع نفسه يمرّر جلسة المستخدم للتطبيق. ارفع نسخة الموقع الجديدة (1xdzbar.zip) على Vercel قبل تجربة الإشعارات.

بناء ملف APK — الطريقة 1: Android Studio
1) ثبّت Android Studio ثم افتح هذا المجلد (1xdzbar-android) منه.
2) انتظر حتى ينتهي Gradle Sync.
3) من القائمة: Build ← Build Bundle(s) / APK(s) ← Build APK(s).
4) تجد الملف في: app/build/outputs/apk/debug/app-debug.apk

بناء ملف APK — الطريقة 2: GitHub (بلا تثبيت أي برنامج)
1) أنشئ مستودعاً على github.com وارفع إليه كل محتويات هذا المجلد (بما فيه مجلد .github).
2) افتح تبويب Actions ← Build APK ← Run workflow.
3) بعد دقائق نزّل الملف المسمى 1xdzbar-apk من أسفل صفحة التشغيل، وفكّ ضغطه لتجد app-debug.apk.

التثبيت على الهاتف
1) انقل app-debug.apk إلى الهاتف وافتحه، واسمح بالتثبيت من مصدر غير معروف.
2) عند أول تشغيل اسمح بالإشعارات.
3) بعد أول تسجيل دخول سيطلب التطبيق استثناءه من توفير البطارية: وافق، حتى تصلك الإشعارات والشاشة مطفأة.
4) في هواتف Xiaomi وHuawei وOppo وغيرها: فعّل أيضاً "التشغيل التلقائي / Autostart" للتطبيق من إعدادات الهاتف.

كيف تعمل الإشعارات؟
- بعد تسجيل الدخول يمرّر الموقع للتطبيق رقم حسابك ورمز تجديد الجلسة.
- خدمة في الخلفية (يظهر لها إشعار صغير دائم "الإشعارات مفعّلة") تتصل بقاعدة Firebase مباشرة وتستمع لمساراتك فقط:
  inbox/UID  ← الرسائل،  friendReq/UID ← طلبات الصداقة،  transfers/UID ← التحويلات.
- تعمل بنفس قواعد قاعدة البيانات الحالية، ولا تحتاج خادماً.
- عند تسجيل الخروج من الموقع تتوقف الخدمة وتُمسح الجلسة من التطبيق.
- لا تظهر إشعارات والتطبيق مفتوح أمامك (الموقع يعرض التنبيه بنفسه).

ملاحظات
- لتغيير رابط الموقع لاحقاً: عدّل SITE في Config.java، والرابط داخل app/src/main/assets/offline.html.
- ملف APK هذا موقّع بمفتاح تجريبي (debug) ويصلح للتثبيت المباشر. للنشر على Google Play تحتاج توقيعاً خاصاً.
- الإشعارات تُبنى على اتصال مستمر، وبعض الهواتف تقتل التطبيقات في الخلفية بقوة؛ الإعدادات في الخطوتين 3 و4 تقلّل ذلك.
